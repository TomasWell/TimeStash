日期：2026-11-07
状态：待实现
作者：与王洋（用户）共同确定

## 1. 为什么做这个

市场上所有时间类工具给的都是**负向反馈**：Screen Time 告诉你刷了 3 小时，Forest 告诉你树死了，番茄钟告诉你超时了。越用越沮丧。

「时间收纳箱」反着来：**提前完成，省下的时间存进箱子，越存越多**。这是一个正向的、可以看见的存款。用户明确说过目的：「长期能帮助人养成不拖沓的习惯」。

顺带解决第二个问题：**人的时间预估本来就不准**。这个 App 记录了每一次「预估 vs 实际」的偏差，慢慢就能反过来修正用户下一次的预估——这是用得越久越值钱的地方。

## 2. 它解决什么问题（用户视角）

| 用户的痛 | App 怎么解决 |
|---|---|
| 一件事拖着不敢开始，因为不知道要花多久 | 开口就要一个预估，30 秒内进入计时，不纠结 |
| 做完了不知道自己是快了还是慢了 | 立刻显示「比预估省了 18 分钟，已存入」 |
| 想变高效但没有正反馈，越用越丧 | 箱子肉眼可见地满起来，是奖励不是考核 |
| 每次预估都不准，永远低估 | 攒够样本后给出分类校准建议 |
| 想知道自己到底把时间花在哪了 | 分类账本 + 趋势图（但只记「省下」，不记「花掉」） |

## 3. 核心机制（整个 App 就这一条主线）

```
用户给一件事定一个预估时长
        ↓
开始计时（预估此刻锁定，不可再改）
        ↓
提前完成 → 省下的时间「入箱」
超时完成 → 不入箱，但照样记录实际用时（数据不浪费）
        ↓
入箱总量 = 所有任务省下的时间之和
        ↓
图表把这份总量讲成故事
```

**时间当钱记**：预估 = 预算，实际 = 支出，省下的 = 存款，箱子 = 账本。

## 4. 目标 / 非目标 / 反目标

**目标**
- 30 秒内开始一件事（从打开 App 到计时开始）
- 每次提前完成都有即时正反馈（入箱动画 + 数字跳动）
- 攒够一周、一个月时，用户能明确感到「我确实变快了」

**非目标**（本次不做，以后可能）
- 团队 / 共享预算
- 自动识别应用使用时长

**反目标（做成这些就是失败）**
- ❌ 变成又一个番茄钟（有循环休息就是番茄钟）
- ❌ 需要后台常驻权限去自动追踪使用时长（耗电、用户不信任、隐私说不清）
- ❌ 有排行榜 / 分享 / 社交（会诱发刷数据，且需要后端）
- ❌ 要注册账号 / 要联网才能用（和现有 5 个 App 一律离线）
- ❌ 首页是一堆数字图表，看不出「箱子」在哪

## 5. 引导页（4 屏，每屏一句话 + 一个画面 + 一个动作）

| 屏 | 文案方向 | 画面 | 动作 |
|---|---|---|---|
| 1 · 痛点 | 「你今天又拖了多久？」 | 一条被拉长的时间条 | 「继续」 |
| 2 · 机制 | 「定好预估，提前完成，省下的存进箱子」 | 三步图解：定 → 计时 → 入箱 | 「继续」 |
| 3 · 体验 | 「先试 1 分钟」 | 预填好的 1 分钟体验任务 | **直接开始计时**（不需点按钮） |
| 4 · 校准基准 | 「你写一份方案大概要多久？」 | 数字输入 | 「开始收纳」 |

**第 3 屏是留存关键**：用户必须在第一分钟就亲眼看到箱子动一下，而不是看完 4 屏空着手离开。

第 4 屏给的数字会作为这个用户所有分类的**初始预估系数基准**。

引导页每屏只有一句话，不堆功能列表（同类 App 的引导页失败原因基本都是信息过载）。

## 6. 主体功能

### 6.1 收纳箱首页（Tab 1）
- **主视觉：一个箱子**，里面是累计省下的时间（小时/天两档单位，自动切换）
- 箱子下方一行：`今日存入 42 分钟 · 本周 3 小时 20 分`
- 一个大按钮「开始一件事」→ 新建任务
- 最近 3 条存入记录（缩略）
- 累计为 0 时的空状态：箱子空着 + 「装满第一个小时」+ 大按钮

### 6.2 新建任务
- 任务名（默认空，键盘直接输入）
- 预估时长：常用快捷（15/30/45/60 分钟）+ 自定义
- 分类：工作 / 学习 / 生活 / 其他（4 个，不要更多）
- 选「按历史校准」时，预估自动乘以该分类的历史系数

### 6.3 计时器
- 大号倒计时 / 正计时（预估越长越可能用正计时，UI 自动切）
- 开始 / 暂停 / 继续 / **提前完成** / 放弃
- **提前完成** → 弹出「省下 18 分钟，已存入」+ 入箱动画
- 超时 → 提示「超时了，这次不入箱」，但仍记录实际用时
- 中途退出（杀进程）→ 下次进来询问「这个还在做吗」，保留计时状态

### 6.4 时间账本（Tab 2）
- 每行：任务名、分类、预估、实际、偏差（绿色 = 快 / 红色 = 慢）
- 支持按分类筛选、按时间倒序
- 可删除单条

## 7. 辅助功能

| 功能 | 说明 | 优先级 |
|---|---|---|
| **里程碑徽章** | 30 分钟 / 1 小时 / 半天 / 1 天 / 1 周 / 1 个月。早期里程碑故意定得很小，让新用户当天就能拿到 | 高 |
| **预估校准提示** | 「你估 1 小时的事平均实际要 80 分钟」+ 一键按比例调整下次预估 | 高（这是护城河） |
| **桌面小组件** | 箱子 + 今日存入 + 「开始一件事」快捷操作 | 高 |
| **通知** | 预估快到时提醒一次；完成时祝贺一次 | 中 |
| **数据导出** | CSV / JSON（和现有 5 个 App 保持一致的习惯） | 中 |
| **Siri / 快捷指令 / App Intent** | 「用 25 分钟写方案」「我攒了多少时间」 | 中 |
| **分类统计** | 按工作/学习/生活/其他拆开 | 中 |
| **无障碍** | VoiceOver 全标签、Dynamic Type 不截断、色盲友好 | 高 |
| **深色模式** | 跟随系统 | 高 |

**关于防刷（重要判断）**：本 App 没有排行榜、没有分享、没有社交，**刷数据的动机极低**（骗自己没意义）。所以不做重投入的反作弊，只做两条最基础的：
1. 计时一旦开始，预估锁定不可改；
2. 单次计入上限 = 预估 × 50%（防止「预估 10 小时、实际 1 秒」刷出巨额存款）。

把工程量省下来做别处。

## 8. 数据模型（GRDB 表）

```swift
struct VaultTask: Codable, Identifiable {
    var id: UUID
    var title: String
    var category: Category     // work / study / life / other
    var estimatedSeconds: Int   // 开始计时后锁定
    var actualSeconds: Int?     // 结束/放弃时写入
    var startedAt: Date?
    var finishedAt: Date?
    var state: State            // planned / running / finished / abandoned
    var savedSeconds: Int       // 实际入箱量（已按 50% 上限截断）
    var createdAt: Date
}

enum Category: String, CaseIterable { case work, study, life, other }
enum State: String { case planned, running, finished, abandoned }
```

- 箱子总量 = `sum(VaultTask.savedSeconds)`，实时算，不另存字段（避免两处不一致）
- 入箱上限：`savedSeconds = min(estimated - actual, estimated / 2)`，且仅当 `actual < estimated` 才 > 0
- 校准系数：按分类算 `median(actual / estimated)`，样本 ≥ 5 个才给建议

## 9. 图表与视觉

**首页只有一个真图表：箱子。** 箱子是自绘的（不是图片资源）——一个箱体轮廓，里面按填充比例往上堆「时间块」，每块代表 1 小时，块上有细纹理表示「本来可以拿去做别的事」。

统计页三个图：

| 图表 | 类型 | 讲什么 |
|---|---|---|
| 累计趋势 | 折线（周 / 月） | 我是不是真的变快了 |
| 分类占比 | 柱状 | 我的时间主要在哪些事上省下来 |
| 里程碑 | 进度条 + 徽章 | 我已经攒下了多少个周末 |

**颜色语义统一**：绿色 = 省下，橙色 = 超时。全 App 一致，账本行、统计图、徽章都用同一对颜色。

**单位策略**：满 1 小时后主显示用「小时 + 分钟」，不足 1 小时只用分钟。不显示「0.5 小时」这种别扭写法。

## 13. 验收标准（做完了必须全部满足）

1. `run_tests.sh` 跑完**用例数 > 0** 且全绿（`xcodebuild` 退出 0 不算数）
2. 新建任务 → 计时 → 提前完成 → 箱子数字增加，整个流程在模拟器上真机跑通并录屏
3. 预估在计时开始后改不动
4. 单次入箱量 ≤ 预估 × 50%
5. 杀掉 App 再回来，计时状态还在
6. 45 个 locale 打包进包里，系统设置里能列出全部语言
7. 隐私清单存在，且商店文案无「完全离线」类绝对表述
8. 图标是矢量手工稿，不是 AI 直接生成图
